\# FIF Calculator Roadmap



\## Phase 0 — Research and Sample Files



Goal: Build confidence before coding too much.



\- Collect anonymised broker CSV/XLSX files

\- Confirm first broker: Sharesies or Hatch

\- Validate FIF formulas with accountant

\- Define canonical data model

\- Build golden test cases



\## Phase 1 — Core Calculator Prototype



Goal: Validate calculation engine.



\- Manual FDR calculator

\- Manual CV calculator

\- Quick-sale worksheet prototype

\- Threshold checker prototype

\- Basic PDF output



\## Phase 2 — One-Broker MVP



Goal: Prove CSV-to-report workflow.



\- Upload parser

\- Broker template

\- Column mapping

\- Transaction normalisation

\- Holdings import

\- Validation dashboard

\- FDR/CV report



\## Phase 3 — Two-Broker Beta



Goal: Prove multi-broker differentiation.



\- Add second broker

\- Consolidate across brokers

\- Handle transfer/duplicate warnings

\- Improve accountant export

\- Add paid report export



\## Phase 4 — Advanced Broker Support



\- IBKR Flex Query support

\- Stake XLSX support

\- Tiger/Moomoo generic imports

\- Better FX and price automation



\## Phase 5 — Paid Launch



\- Free threshold check

\- Paid PDF/CSV export

\- Saved portfolio option

\- Support workflow

\- Accountant feedback loop



\## Phase 6 — Advanced NZ Features



\- Cost method support

\- RAM screening/support

\- Corporate action automation

\- Historical price API

\- IRD disclosure helper

\- Accountant portal



\## Phase 7 — Australia Discovery



Only start after NZ traction.
