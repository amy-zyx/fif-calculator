# FIF Calculator

A New Zealand FIF calculator that helps investors upload broker CSV/XLSX files and generate reviewable FIF taxable income working papers.

## Product Goal

Help NZ investors calculate FIF income from overseas shares, ETFs, and foreign funds without manually entering every transaction into calculators or spreadsheets.

## MVP Scope

- NZ income year selection
- CSV/XLSX upload
- Broker/file type detection
- Column mapping
- Transaction normalisation
- Holdings reconstruction
- FDR calculation
- CV calculation
- Quick-sale adjustment
- FIF threshold checker
- PDF/CSV working-paper export
